# 🚀 STAMINAC – AI Registration & Hall Ticket Management System

**STAMINAC – Stellar Learning Lab** is a Space and STEM Awareness Olympiad initiative designed to encourage students from Classes 5 to 10 to explore the fascinating worlds of Science, Technology, Mathematics, Astronomy, Astrophysics and Cosmology.

🌐 **Live Registration Portal:** https://staminacregistrationup.netlify.app

## 🌌 About the Project

The STAMINAC Registration Portal is an administrator-operated digital registration and hall-ticket management platform. It is designed to simplify the process of registering students who submit offline registration forms and preparing their examination hall tickets.

The platform provides a central interface for reviewing registration details, managing authorised student records, and generating printable hall tickets.

## ✨ Main Features

### 1. Registration AI Interface
- Capture an offline registration form using a camera.
- Upload an existing photograph of a registration form.
- Display the uploaded photograph for reference.
- Enter and verify student information manually before authorisation.
- Preview the candidate photograph on the hall ticket.

### 2. Student Registration Management

The registration interface supports the following student information:

- Student name
- Class
- Section
- School name
- Email address
- Selected Olympiad level
- Parent or guardian name
- Registration ID field
- Candidate photograph

Administrators can review the details and authorise a registration.

### 3. Automatic Hall Ticket Generation

After authorisation, the system generates a hall ticket number based on the selected Olympiad level.

Example:

`SSLBSTAMINACLVL12026001`

The generated hall ticket includes:
- Candidate name and photograph
- Class and section
- School name
- Olympiad level
- Unique hall ticket number
- Examination name
- 75 multiple-choice questions
- Two-hour examination duration
- Candidate and parent/guardian signature spaces

### 4. Registered People Dashboard

The Registered People section provides a consolidated view of authorised candidates.

Administrators can view:
- Hall ticket number
- Student name
- Class
- School
- Selected level
- Registration status

### 5. Hall Ticket Preview & Print Centre

The Print Centre allows administrators to:
- View registered candidates.
- Select an individual candidate.
- Open the candidate's hall ticket preview.
- Print the hall ticket using the browser's print function.
- Save a printable HTML version of the hall ticket.

## 🛠️ Technology Stack

- HTML5 – Page structure
- CSS3 – Responsive interface and styling
- JavaScript – Registration, dashboard navigation and hall-ticket generation
- Browser Local Storage – Local registration record storage
- Browser Camera API – Capturing registration form photographs
- Netlify – Website deployment and hosting

## 🎯 Vision

The goal of STAMINAC is to make space education exciting, accessible and challenging for students. The registration portal is an important part of the larger Stellar Learning Lab initiative, helping organise student participation in space-focused Olympiad examinations.
